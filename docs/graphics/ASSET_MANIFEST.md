# Asset manifest

All assets are original, generated by code in this repository. No third-party models, textures
or audio are bundled. Blender is **not** installed in the build environment; nothing here was
authored in Blender. The glTF files are produced by procedural three.js builders run in Node
and exported with `GLTFExporter`, so they open in Blender or any glTF 2.0 viewer.

Regenerate everything with `node tools/assets/build.mjs`; the machine-readable list is written to
`public/models/manifest.json`.

Named materials inside each model (`paint`, `glass`, `accent`, `decal-left/right/rear`, `headlight`,
`rubber`, `rim`, `chrome`, …) are remapped at runtime for per-vehicle paint, EGO HVAC wordmark
decals and headlights. Node names `wheel_*`, `steer_*`, `rack` and `chassis` drive animation.

## Procedural geometry built in the browser (`src/world/`)

| Category | Source | Technique |
| --- | --- | --- |
| Houses (5 archetypes) | `buildings/HouseBuilder.ts` | Boxes, extruded roofs, explicit hip/gable faces merged per material; ~11 draw calls per lot |
| Headquarters | `buildings/HeadquartersBuilder.ts` | Merged campus; animated bay doors as separate meshes |
| Warehouse, competitor, park | `buildings/Commercial.tsx` | Box construction |
| Roads, sidewalks, signs | `roads/Roads.tsx` | One merged mesh per material; textured street blades |
| Terrain, mountains | `city/Ground.tsx` | Displaced plane and ring meshes |
| Vegetation (12 species) | `city/Vegetation.tsx` | One geometry per species with vertex colors, drawn as `InstancedMesh` |
| Characters | `characters/Worker.tsx` | Capsule/box rig with procedural clips |
| Condenser units | `buildings/parts.tsx` | Box, louvers, fan grille |

## Animation

| Target | Clips | Driver |
| --- | --- | --- |
| Vehicles | wheel spin, front steer, chassis roll/pitch, headlights | rendered motion derived from simulation position and heading |
| Characters | idle, walk/carry, kneel-inspect, kneel-repair, stand-inspect, install lift, train, celebrate | employee status and job status |
| Headquarters | bay door roll-up | any vehicle moving inside the lot |
| Atmosphere | sun, sky, fog, exposure, lamps, rain | game clock and daily weather |
